# نسخة ضد السينما !؟ — لوحة التحكم

هذه النسخة تحول الموقع إلى واجهة تعتمد على `data/site.json` وتضيف Decap CMS في `/admin/`.

## ماذا تستطيع من لوحة التحكم؟

- تعديل الصفحة الرئيسية والنصوص والبريد والعدد الحالي.
- إضافة وحذف وتعديل الأقسام.
- إضافة الأعداد التسعة وتعديلها وإضافة أعداد جديدة.
- رفع غلاف كل عدد.
- رفع PDF لكل عدد مباشرة إلى `uploads/issues`.
- إضافة وحذف وتعديل المقالات.
- إضافة صور المقالات.
- إدارة هيئة التحرير والكتاب والوسائط وسياسة الموقع.

## تشغيلها على GitHub Pages

1. ارفع محتويات هذه الحزمة إلى مستودعك الحالي `mohamedihakim09-spec/-contre-cinema` واستبدل `index.html` بالنسخة الجديدة الموجودة في الحزمة.
2. أنشئ موقعاً في Decap Turbo واربطه بمستودع GitHub نفسه، والفرع `main`.
3. ضع رابط لوحة التحكم:
   `https://mohamedihakim09-spec.github.io/-contre-cinema/admin/`
4. انسخ `Site ID` الذي يعطيه Decap Turbo وضعه مكان `YOUR_TURBO_SITE_ID` داخل `admin/config.yml`.
5. بعد الحفظ، افتح `/admin/` وسجّل الدخول.

مهم: GitHub Pages يستضيف الملفات الثابتة، لذلك المصادقة وحفظ التعديلات في GitHub تحتاج إلى Backend مثل Decap Turbo؛ لا يمكن تنفيذ تسجيل الدخول الآمن إلى لوحة الإدارة بواسطة HTML فقط.
