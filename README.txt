ضد السينما !؟ — الموقع الرسمي (contrecinema.com)

### هيكل الملفات:
* `index.html` — واجهة الموقع الرئيسية
* `section.html` — صفحة قسم: `section.html?slug=اسم القسم`
* `author.html` — صفحة كاتب: `author.html?name=اسم الكاتب`
* `style.css` — تنسيقات الموقع
* `app.js` — منطق الموقع وجلب البيانات من Supabase (بما فيه شريط المشاركة)
* `cc-control.html` — لوحة التحكم (بلا رابط ظاهر للزوار: من الموقع بـ Ctrl+Shift+A)
* `admin.css` / `admin.js` — تنسيقات اللوحة ومصادقتها وإدارة المحتوى
* `assets/` — الشعار والأيقونات وصورة المشاركة (og:image)
* `CNAME` — ربط النطاق contrecinema.com (لا يُحذف)
* `supabase/migrations/` — سجل تغييرات قاعدة البيانات

### ملاحظات:
- كل المحتوى (الأعداد، المقالات، الأقسام، هيئة التحرير، المحررون، إعدادات الواجهة) يُدار من قاعدة Supabase عبر اللوحة.
- الوضع الليلي/النهاري مدعوم في الموقع واللوحة معاً، ويُحفظ محلياً في المتصفح.
- المقال المخفي (visible=false) لا يظهر للزوار ولا في صفحات الأقسام والكُتّاب.
- هذا الملف (README) لا يلزم رفعه، يمكنك حذفه أو تعديله كما تشاء.
